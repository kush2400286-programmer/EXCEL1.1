# Excel Roadmap

A step-by-step learning roadmap for mastering Microsoft Excel from beginner to professional level, with a focus on practical skills and job preparation.

## Overview

- **Duration:** Approximately 8 weeks
- **Daily practice:** 1–2 hours
- **Goal:** Build Excel skills for data analysis, office reporting, and entry-level analyst roles

> The timeline is a guide. Professional proficiency depends on consistent practice and the complexity of the work.

## Learning Path

### Level 1: Basic Excel — Weeks 1–2

Learn how Excel works and how to organize simple data.

- Workbook, worksheet, rows, columns, and cells
- Data entry: text, numbers, dates, and autofill
- Formatting: fonts, borders, colors, and number formats
- Basic formulas: `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`
- Relative and absolute references: `A1` and `$A$1`
- Sorting and filtering
- Useful shortcuts: `Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+Shift+L`

**Practice task:** Create a marks sheet for 20 students. Calculate total and average marks, and identify the highest score.

### Level 2: Intermediate Excel — Weeks 3–4

Learn formulas and tools commonly used in workplace reporting.

| Function / Tool | Purpose |
|---|---|
| `IF` | Check a condition |
| `SUMIF` / `SUMIFS` | Sum values that meet conditions |
| `COUNTIF` / `COUNTIFS` | Count values that meet conditions |
| `IFERROR` | Handle formula errors |
| `XLOOKUP` | Find matching information in another range |
| `VLOOKUP` | Perform lookups in older Excel workflows |
| `LEFT`, `RIGHT`, `MID` | Extract parts of text |
| `TRIM` | Remove extra spaces |
| `AND`, `OR` | Test multiple conditions |

Example:

```excel
=IF(B2>=40,"Pass","Fail")
```

This returns `Pass` when the value in `B2` is 40 or greater; otherwise, it returns `Fail`.

Also practise data cleaning, date functions, and dropdown lists using Data Validation.

### Level 3: Advanced Excel — Weeks 5–6

Learn to analyse larger datasets and answer business questions.

- PivotTables and PivotCharts
- Conditional Formatting
- Excel Tables
- Data Validation
- Dynamic array functions: `FILTER`, `SORT`, `UNIQUE`
- Date functions: `TODAY`, `YEAR`, `MONTH`, `EOMONTH`
- What-if Analysis: Goal Seek and Scenario Manager
- Chart selection and clear data presentation

**Practice task:** Analyse sales data to find the best-performing month, top-selling products, and highest-revenue cities.

### Level 4: Professional Excel — Weeks 7–8 and beyond

Build reporting and automation skills used in real projects.

#### A. Dashboard creation

- KPI cards
- Bar and line charts
- PivotCharts and Slicers
- Consistent formatting and interactive reports

#### B. Power Query

- Remove duplicate records
- Check and handle missing data
- Split and combine columns
- Append or merge tables
- Import and transform multiple files

#### C. Power Pivot and DAX

- Create relationships between tables
- Build data models
- Write measures for more advanced reporting

#### D. Macros and VBA

- Automate repetitive tasks
- Record and review macros
- Learn VBA basics when relevant to your role

Power Pivot, DAX, and VBA are useful for some roles, but they are not required for every Excel job.

## 8-Week Study Plan

| Week | Topics |
|---|---|
| 1 | Interface, data entry, formatting, basic formulas |
| 2 | Sorting, filtering, cell references, practice sheet |
| 3 | `IF`, `SUMIFS`, `COUNTIFS`, text functions |
| 4 | `XLOOKUP`, `VLOOKUP`, data cleaning |
| 5 | PivotTables, PivotCharts, Conditional Formatting |
| 6 | Advanced formulas, dynamic arrays, charts |
| 7 | Power Query and dashboard design |
| 8 | Complete a project, validate results, prepare a portfolio |

### Suggested daily routine

- **20 minutes:** Learn a concept
- **40 minutes:** Practise in Excel
- **20 minutes:** Solve exercises without following a tutorial

## Portfolio Projects

Complete these three projects to demonstrate your skills.

### Project 1: Sales Analysis

- Monthly revenue
- Top-selling products
- City-wise sales
- Sales trends and charts

### Project 2: Employee Report

- Department-wise headcount
- Attendance summary
- Salary analysis
- Filters and PivotTables

### Project 3: Interactive Dashboard

- KPI cards
- PivotTables and charts
- Slicers and filters
- A concise summary of business insights

Use sample or public datasets, and avoid publishing confidential personal or company information.

## Recommended Next Steps for a Data Analyst

After building a solid Excel foundation, consider learning:

1. **SQL** — retrieve and query data
2. **Power BI** — build interactive business dashboards
3. **Statistics** — understand trends, variation, and comparisons
4. **Python** — automate analysis and work with larger datasets

You can start learning basic statistics and analytical thinking alongside Excel.

- [ ] Learn conditional formulas and lookups
- [ ] Clean and validate data

## Final Advice

Consistency matters more than speed. Practise with real-looking datasets, check your results, and build projects that show how you turn raw data into useful information.
